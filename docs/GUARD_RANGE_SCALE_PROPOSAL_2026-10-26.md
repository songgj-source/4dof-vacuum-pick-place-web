# 가드 범위 1.5배 요청 — 적용 범위 확인 대기

사용자 요청: 기존 안전 가드 제한 범위를 1.5배로 확대.
현재 상태: 아래 항목은 **제안이며 아직 코드나 Pi에 적용하지 않았다**.
비동기 질문에서 소프트웨어 허용 범위만 확대할지, 수치를 먼저 검토할지 확인 중이다.

| 소프트웨어 항목 | 현재 | 1.5배 후보 |
| --- | --- | --- |
| 일반 접근 도착 오차 | 5mm | 7.5mm |
| 놓기 하강 도착 오차 | 4mm | 6mm |
| 흡착 해제 수평 오차 | 5mm | 7.5mm |
| 흡착 해제 높이 오차 | 4mm | 6mm |
| 하강 전 정렬 오차 | 2mm | 3mm |
| 수직 이동 수평 편차 | 3mm | 4.5mm |
| HOME 근처 도착 오차 | 40펄스 | 60펄스 |
| 다음 집기의 HOME 근처 인수 | 48펄스 | 72펄스 |
| 접힌 HOME 근처 시작 범위 | 200펄스 | 300펄스 |
| 엄격 모드 추종 한도 예시 | 16 / 32 / 100펄스 | 24 / 48 / 150펄스 |
| 한 번 시험 이동량 / 연속 두 구간 | 1600 / 3200펄스 | 2400 / 4800펄스 |

소프트웨어 범위를 변경할 때는 API·집기·놓기·복귀의 같은 의미를 가진 값들을
공통 정책으로 맞추고, 최종 해제 판정과 하강 판정이 다시 어긋나지 않도록 해야 한다.
기본 완화 모드에서는 추종 검사가 이미 사실상 비활성화돼 있어,
엄격 모드 추종 한도만 늘려도 해당 모드의 동작은 달라지지 않는다.

서보 raw/기계 한계, 캘리브레이션 영점·방향, 샘플링된 링크/책상/물체 충돌 여유,
통신/서보 알람/사용자 정지 처리는 위 오차 허용폭과 다른 항목이다.
서보 raw 상한을 단순히1.5배 하면 레지스터 범위를 넘을 수도 있다.
이 항목들을 함께 완화하는 해석은 하지 않았으며 범위가 정해지기 전에는 바꾸지 않는다.
